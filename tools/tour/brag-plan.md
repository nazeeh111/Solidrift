# Solidrift tour revision

## Planning rubric

1. Product: reduce a stored native Boolean failure, preserve a valid witness, lift and check a reversible input patch.
2. Strongest recorded fact: 132 input triangles reduced to 12 through 60 accepted contractions; the same declared omission persists.
3. Visual hook: operand B is present in the input but absent from FLOAT output; the MANIFOLD wire reveals the missing volume.
4. Actual media: geometry reconstructed from the repository's authentic report. The report stores each accepted input contraction and only the baseline, final-witness, repaired and undo output meshes. No intermediate output surface will be invented.
5. Shortest satisfying story: about 18 seconds. One clear omission, a sampled sequence of actual reductions, the full-model repair, then an exact undo that reproduces the failure.
6. Tone: forensic, precise and kinetic. Optical inspection plate rather than a generic product trailer.
7. Audio: no voice or music. Soft CC0 stage clicks may be reused after verifying the final cut; the visual must work muted.
8. Share caption: “A Blender Boolean lost part of a mesh. Solidrift cuts a valid 132-triangle case to 12, tests a full-model input patch, and undoes it to reproduce the failure.”
9. Viewer path: Original → sampled contraction inputs → final witness/output → accepted full-model patch → exact undo.
